新建桥

一座桥连接一个 Telegram 机器人和一个 Muse 实例。机器人 token 会加密存储，Muse 永远看不到它。

在 Telegram 里私聊 @userinfobot， 它回你的那串数字就是你的 ID。只有这些 ID 发来的消息才会被接收并交给 Muse，其他人发的直接丢弃、不入库。 多个 ID 用逗号隔开。
